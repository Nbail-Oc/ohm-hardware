# Ohm Smart Wearable - Hardware & Firmware

> Hardware designs and embedded firmware for Ohm smart wearable

---

## 🚀 Overview

Schematics, PCB layout files, sensor integration code, and micro-controller firmware for the Ohm wearable wristband.

---

## 🛠️ Tech Stack

`C++` • `Embedded C` • `KiCad` • `Arduino / ESP32`

---

## ✨ Key Features

- **Biometric PPG and accelerometer sensor drivers**
- **BLE (Bluetooth Low Energy) communication stack**
- **Ultra-low-power sleep management routines**

---

## 📦 Getting Started

### Prerequisites

Ensure you have the appropriate runtime installed (Node.js 18+ or Python 3.10+ depending on project stack).

### Installation

```bash
# Clone the repository
git clone https://github.com/Nbail-Oc/ohm-hardware.git

# Navigate into the project directory
cd ohm-hardware
```

### Setup & Run

- If this is a **Node.js / Next.js** project:
  ```bash
  npm install  # or pnpm install / yarn
  npm run dev
  ```

- If this is a **Python / FastAPI** project:
  ```bash
  python -m venv venv
  source venv/bin/activate  # On Windows: .\venv\Scripts\activate
  pip install -r requirements.txt
  python main.py  # or uvicorn main:app --reload
  ```
